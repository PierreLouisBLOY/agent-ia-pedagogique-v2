# Phase 12.16-G2-V5.1 — Audit Strong/Mixed/Weak selon la rubrique

## Rubrique appliquée

Critère : `scn-06.quality.marking-scheme-coherence`.

Les quatre contrôles V5.1 sont :

1. points répartis par question;
2. attribution identifiable pour la formule;
3. attribution identifiable pour l'application numérique;
4. résultat, unité et vérification alignés avec les points.

Le niveau vaut le nombre de contrôles satisfaits, sauf contradiction matérielle qui
force le niveau `0`. Les libellés historiques Strong/Mixed/Weak ne sont pas utilisés
comme preuve.
